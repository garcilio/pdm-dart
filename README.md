# Programação para Dispositivos Móveis (PDM)

Repositório dedicado à resolução dos exercícios práticos da unidade curricular de Programação para Dispositivos Móveis, desenvolvidos em Dart.

---

## Tecnologias Utilizadas

- **Linguagem:** Dart
- **Editor:** Visual Studio Code

---

## Lista de Exercícios

|     Ficheiro      | Descrição |
| :--- | :--- |
| `exercicio1.dart` | Introdução à sintaxe, variáveis e tipos de dados |
| `exercicio2.dart` | Segurança Nula (Null Safety) e Modificadores de Inicialização em Dart |
| `exercicio3.dart` | Funções em Dart: Parâmetros, Arrow Syntax e Funções Anónimas |
| `exercicio4.dart` | Coleções e Operações com Coleções em Dart (`List`, `Map`, `Set`) |
| `exercicio5.dart` | Programação Orientada a Objetos (POO): Classes, Enums, Imutabilidade e Padrões em Dart |
| `exercicio6.dart` | Programação Assíncrona em Dart: `Future`, `async`/`await` e manipulação com `.then()` |
| `exercicio7.dart` | Tratamento de Exceções e Erros Personalizados em Dart (`try-catch-finally` e `Exception`) |
| `exercicio8.dart` | Operações Concorrentes com `Future.wait()`, Benchmarking e Gestão de Tempos-Limite (`timeout`) |
| `exercicio9.dart` | Streams e Geradores Assíncronos em Dart (`Stream`, `async`, `yield` e `await for`) |
